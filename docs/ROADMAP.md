# Delivery roadmap

Status: **Planned**, **In progress**, **Verified**, or **Blocked**. A task is not complete until its acceptance checks pass.

## Phase 0 — Repository foundation
- [x] Project overview and product brief.
- [x] Monorepo workspace configuration.
- [x] Architecture, security principles, and roadmap.
- [ ] CI, formatting, linting, and automated tests.
- [ ] Contribution and issue templates.

## Phase 1 — Web and mobile foundations
- [ ] Responsive web shell and design tokens.
- [ ] Expo mobile application.
- [ ] Localization framework and RTL/LTR support.
- [ ] Accessible navigation and reusable form components.

## Phase 2 — Identity and profiles
- [ ] Configure Supabase and environment variables.
- [ ] Authentication and email verification.
- [ ] Candidate and organization profiles.
- [ ] Organization membership and permissions.
- [ ] Privacy settings and account deletion.

## Phase 3 — Core recruitment
- [ ] Vacancy publishing and moderation states.
- [ ] Search, filters, and saved vacancies.
- [ ] CV upload with private storage.
- [ ] Applications and status tracking.
- [ ] Employer candidate review tools.

## Phase 4 — Trust and administration
- [ ] Employer verification.
- [ ] Reports, moderation, and audit logs.
- [ ] Anti-spam and abuse controls.
- [ ] Admin dashboard.

## Phase 5 — Monetization and alerts
- [ ] Country-aware plans and entitlements.
- [ ] Suitable payment providers per launch market.
- [ ] Verified webhooks, invoices, cancellation, and refunds.
- [ ] Saved searches and notification preferences.
- [ ] Push, email, and in-app alerts.

## Phase 6 — Global readiness
- [ ] Reviewed translations and locale-aware formatting.
- [ ] Country, currency, and time-zone configuration.
- [ ] Jurisdiction-specific privacy, employment, consumer, and tax review.
- [ ] Accessibility and security reviews.

## Phase 7 — Release
- [ ] Automated and manual QA.
- [ ] Monitoring, backups, and incident response.
- [ ] Production web deployment.
- [ ] Android and iOS store preparation.
- [ ] Limited pilot before broad launch.

## Release gate
No phase is production-ready until critical user journeys, authorization rules, failure states, accessibility checks, and relevant automated tests have been verified.
